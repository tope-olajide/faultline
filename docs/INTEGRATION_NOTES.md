# Faultline — Integration Notes

Internal engineering document. Tracks external systems, credentials, and
simulator boundaries.

## Credential requirements

| Integration | Credentials needed | Available now | Behaviour without credentials |
|---|---|---|---|
| HydraDB (self-hosted) | Bearer token (local dev token in `.hydradb/auth-token`, generated by `npm run setup`) | Yes — generated locally | App fails fast with a typed 503 and a specific message; no mock fallback |
| Prometheus / Alertmanager | Base URL + optional basic auth token | No | Simulator adapter serves deterministic metric and alert evidence (Slice 2–3) |
| Grafana Loki | Base URL + tenant/org id | No | Simulator adapter serves log-pattern evidence |
| Jaeger / Tempo | Query base URL | No | Simulator adapter serves trace references |
| GitHub | Fine-grained PAT (read-only: contents, deployments, PRs) | No | Simulator adapter serves commits/deployments |
| Kubernetes | Kubeconfig or in-cluster service account (read-only) | No | Simulator adapter serves workload/event evidence |
| LLM provider | API key **or** local Ollama | No | Deterministic reasoning engine produces hypotheses; narration is generated from structured facts |

**Rule:** every integration is an adapter behind a common interface. A missing
credential produces a *labelled simulated source* in the evidence payload, never a
silent fake, and never a hardcoded result in production paths.
